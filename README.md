# Puppygo_mando

## Mando web

Mando web por Bluetooth para el perro robot PuppyGo. Ábrelo con Chrome en Android (hace falta Web Bluetooth).

En Chrome: menú → **Añadir a la pantalla de inicio** o **Instalar aplicación**. Queda como app, con icono, y funciona también en la ruta `/Puppygo_mando/` de GitHub Pages.

Para publicarlo, GitHub Pages tiene que servir la rama `main` desde la carpeta raíz (`/`).
